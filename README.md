Ansible [NeoGo Legacy][neogo] role.
=========

**This role is deprecated, archived and no longer maintained.**
Neo Legacy testnet was closed June 1 2025, mainnet deadline is Oct. 31 2025.
Protocol development has stopped years before that, please switch to N3 and
use [ansible-neogo-n3](https://github.com/nspcc-dev/ansible-neogo-n3) to manage it.

This role deploys [NeoGo node][neogo] for [Neo][neo] Legacy.

[neogo]: https://github.com/nspcc-dev/neo-go
[neo]:   https://neo.org
